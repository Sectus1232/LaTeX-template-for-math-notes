# Advanced LaTeX Typesetting: Functional Analysis

This repository serves as a technical portfolio demonstrating advanced document structuring, macro programming, and mathematical typesetting using LaTeX. 

**Tech Stack:** `LaTeX`, `TikZ` (Vector Graphics), `tcolorbox` (Custom Environments), `BibLaTeX`.

## About the Project
The project contains the source code and compiled documentation for a comprehensive introduction on Functional Analysis. Beyond the mathematical content, it highlights strict typographical control and scalable document architecture.

Key technical features implemented in this repository include:
* **Custom Macro Development:** Programmed specific environments for definitions, theorems, and proofs using `tcolorbox`, ensuring visual consistency across hundreds of pages.
* **Vector Graphics:** Implementation of automated and scalable diagrams, including Kripke models and state graphs, programmed directly in the mathematical engine using `TikZ`.
* **Scalable Architecture:** Modular document design managing complex cross-referencing, custom indexing, and automated bibliography generation.
* **Typographical Rigor:** Strict adjustment of margins, tracking, and leading using packages like `geometry` and `microtype` to meet professional publishing standards.
